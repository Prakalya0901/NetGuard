
# NetGuard
## Network Intrusion Detection System Using Python

### Project Description
NetGuard is a Python-based cybersecurity application
that analyzes network logs and identifies suspicious
activities.

### Features
1. Port Scan Detection
2. Brute Force Detection
3. Traffic Spike Detection
4. IP Address Tracking
5. Automatic Security Alerts
6. Security Report Generation

### Technologies
- Python
- CSV
- Datetime
- Collections
- IP Address Validation

### Execution
Run the following command:

python main.py

Enter the CSV file name:

sample_logs.csv

### Output
The program identifies suspicious activities and
generates a security_alerts.txt report.

### Project Domain
Cybersecurity and Network Security

Third Year Mini Project
